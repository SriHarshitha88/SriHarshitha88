Software engineer interested in building thoughtful web products and reliable AI-powered systems.

I enjoy working across product and engineering—from shaping an idea and designing the user flow to building the interface and backend. I care about clear documentation, sensible tradeoffs, and systems that remain understandable when something goes wrong.
